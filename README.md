# Antigravity IDE Frontend

A pixel-perfect frontend clone of the Antigravity IDE — built with pure HTML, CSS, and JavaScript.

## Features

- Full VS Code-style workbench layout
- Activity Bar with Explorer, Search, SCM, Debug, Extensions
- Tabbed editor with syntax highlighting
- Integrated terminal (interactive)
- Jetski AI chat panel (Gemini-powered UI)
- Command Palette (Ctrl+Shift+P)
- Dark/Light theme toggle
- Resizable sidebar and panel
- Status bar with Git info
- Context menus and notifications
- Keyboard shortcuts
- Codicon icon font (from Antigravity IDE)

## Stack

- HTML5 + Vanilla CSS + Vanilla JavaScript
- Codicon font (VS Code icon set)
- No dependencies, no build step

## Usage

Open `index.html` directly in a browser — no server required.
